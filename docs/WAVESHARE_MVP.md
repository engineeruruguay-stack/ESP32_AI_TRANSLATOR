# Waveshare ESP32-S3-AUDIO-Board MVP

Плата ESP32-S3R8, Flash 16 МБ. Управление через K1, K2 и BOOT и кольцо из семи светодиодов. Исходный проект использует ESP-IDF, таблицу разделов с OTA и драйвер WS2812B. Историческая HTTP-панель доступна по настройке, по умолчанию выключена.

## Сборка и прошивка

```sh
. /path/to/esp-idf/export.sh
idf.py set-target esp32s3
idf.py build
idf.py -p /dev/cu.usbmodemXXXX flash monitor
```

CI использует ESP-IDF 5.5.2. В меню `idf.py menuconfig → Waveshare Audio MVP` задайте SSID, пароль и IPv4-адрес шлюза. Файл `sdkconfig` игнорируется Git. Указанные через menuconfig параметры Wi-Fi попадают в локальный бинарник. Используйте стандартную сборку с пустыми параметрами для передачи другим людям. Для диагностики и SD Wi-Fi необязателен.

Готовый объединённый образ содержит загрузчик, таблицу разделов, начальные OTA-данные и приложение. Прошивка объединённого образа по адресу 0x0 перезапишет разделы в пределах образа, включая область NVS. Выход из монитора ESP-IDF — Ctrl+].

## Управление и проверка на плате

При включении кольцо показывает зелёный режим и плата запускает первый MP3 с microSD, если находит файл. Управление работает по отпусканию K1. K3 исключена из управления.

| RGB | Режим | Короткое нажатие K1 | Удержание K1 от 0,7 до 2,5 с |
| --- | --- | --- | --- |
| Зелёный | Музыка | Запустить или остановить трек | Следующий трек |
| Синий | Испанский → русский | Начать или закончить захват | Отменить сеанс |
| Фиолетовый | Русский → испанский | Начать или закончить захват | Отменить сеанс |
| Белый | Диагностика | Тон, пики двух слотов микрофонов и поиск MP3 | Статус Wi-Fi в журнале |

Для смены режима удерживайте K1 около 3 секунд и отпустите. Порядок после включения: зелёный, синий, фиолетовый, белый, зелёный. Краткий красный сигнал обозначает ошибку операции.

1. Подключите USB. В журнале проверьте TCA9555 0x20, ES7210 0x40, ES8311 0x18 и результат монтирования microSD. Плата ищет до 64 MP3 в корне FAT32 и сортирует их по имени. По окончании трека автоматически включается следующий, после последнего — первый. Выход 16 кГц, моно. Стартовая амплитуда 5%, максимум 10% для всех режимов.
2. В белом режиме коротко нажмите K1. Проверьте тон и отдельно поднесите источник звука к каждому микрофону. В журнале должны меняться пики соответствующих слотов.
3. Для проверки Wi-Fi дождитесь IP в журнале. Запустите шлюз на компьютере в той же локальной сети и проверьте возвращаемый голос в обоих направлениях.

В музыкальном режиме короткое K2 добавляет один процентный пункт, удержание около секунды переключает на следующий трек. Короткое BOOT убавляет один процентный пункт, удержание включает предыдущий. BOOT используется после запуска платы.

## Тест потока ES↔RU

```sh
python3 python/mvp_gateway.py --bind 0.0.0.0 --port 8765
```

TCP без шифрования для стенда в доверенной локальной сети. Плата передаёт строку `WV1 ES RU\n` или `WV1 RU ES\n`, затем последовательно посылает блоки PCM 16 кГц, mono, signed 16-bit little-endian. Сеанс захвата ограничен 15 секундами. Конец входа обозначается закрытием направления записи TCP. Плата воспроизводит ответ того же формата по мере поступления и завершает сеанс по EOF. Встроенный динамик включается на воспроизведении.

Тестовый Python-шлюз возвращает исходный PCM. Интерфейс для провайдера расположен на стороне шлюза. Он должен принимать порции PCM, проводить STT → перевод → TTS для указанной пары языков и отдавать PCM. Ключи будущего провайдера следует задать в окружении процесса на сервере. Этот MVP проводит один разговорный ход за сеанс.

## Внешний Bluetooth-передатчик

ESP32-S3 не поддерживает Bluetooth Classic/A2DP. Для обычного наушника предусмотрен внешний **A2DP Source**. Кандидат на прототип — отдельный ESP32 с Bluetooth Classic и преобразователем формата PCM/SBC. На физическом прототипе цифровой звук можно снять с линии I2S через доступные точки платы, используя вход в режиме slave и общий GND. Такты остаются под управлением Waveshare, текущий PCM — 16 кГц в двух слотовых каналах. Модуль должен поддерживать этот вход или пересчитывать частоту перед A2DP. Расположение точек подключения, электрическая схема моста, его прошивка и сопряжение требуют отдельной проверки. Выход мостового усилителя динамика нельзя напрямую использовать как линейный вход передатчика.
